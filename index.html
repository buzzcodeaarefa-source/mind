Data Storage & Backups

MindVault stores your entire workspace inside your web browser's LocalStorage. No data is sent to external servers. To avoid losing notes if browser history is purged, export regular JSON backups.

Export Vault Backup (JSON) Download a comprehensive timestamped JSON snapshot of all notes, tasks, journals, and sessions.
Export All Notes (Markdown) Download all your active notes formatted as pure Markdown files in a combined bundle.
Import Vault Backup Restore from a previous MindVault JSON backup file.
Sample Workspace Data Load realistic sample notes, tasks, and journals to explore MindVault's capabilities.
Reset All Vault Data Permanently purge all notes, tasks, journals, and local settings. This action cannot be undone.
